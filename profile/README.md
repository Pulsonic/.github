# Pulsonic

**From field measurements to web applications.**

[Pulsonic](https://www.pulsonic.com/en/home/) is a French company designing and manufacturing meteorological and hydrological observation systems since 1984. We build the instruments and software that help organizations collect, monitor, and use environmental data.

Our development work connects two worlds:

- **Firmware & embedded systems** — software for observation stations, sensors, and data loggers, bringing together measurement acquisition, local processing, and communications with a focus on reliable operation and low power consumption in the field.
- **Web applications & data services** — tools that turn observations into useful information. [Pulsoweb](https://www.pulsonic.com/en/home/software/pulsoweb/) brings together data collection, quality control, interactive dashboards, network supervision, and data exchange, with cloud and on-premises deployment options.

From embedded devices to browser interfaces, we develop connected tools for meteorology, hydrology, and environmental monitoring.
